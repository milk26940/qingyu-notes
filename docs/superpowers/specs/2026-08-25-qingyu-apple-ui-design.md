# 轻羽 Apple 风格界面设计

## 目标

在不改变三栏信息架构、页面树、编辑器和 Agent 功能的前提下，把轻羽统一为 macOS 风格的极简笔记界面，并支持左右栏实时拖拽调宽。

## 视觉

- 窗口背景使用纯净浅灰，顶栏和三栏主体使用白色、18-24px 圆角与柔和阴影。
- 顶栏品牌使用灰色 Feather 线稿图标和“轻羽”，标签仍位于顶栏。
- 主文字使用接近黑色，正文与右栏辅助文字使用深灰，避免低对比度文本。
- 按钮、菜单、输入框和弹层统一圆角，并提供 220ms 的缩放与透明度反馈。
- 空白编辑区显示羽毛图标卡片、主标题“选择或新建一个页面”和副标题“从左侧页面树打开笔记”。

## 布局

- 保留左侧页面树、中间编辑区、右侧 Agent 三栏。
- 左侧宽度限制为 220-420px，右侧宽度限制为 300-560px，中间区至少保留 480px。
- 两条边界使用清晰深灰实线，中央提供胶囊形拖拽手柄；悬浮和拖拽时高亮。
- 用户调整后的宽度保存到 localStorage，重启后恢复。
- 左右栏折叠时对应分隔手柄隐藏。

## 组件边界

- `workspaceStore.ts` 管理宽度、约束和持久化。
- `PanelResizeHandle.tsx` 只负责指针拖拽和键盘调节。
- `WorkspaceShell.tsx` 负责组合三栏、分隔条和圆角容器。
- `index.css` 提供统一的颜色、圆角、阴影与交互动效。
- 顶栏、侧栏、Agent、目录与空白页只调整呈现，不改变业务数据流。

## 验证

- 组件测试覆盖左右拖拽手柄、宽度约束和品牌图标。
- 运行前端测试和 TypeScript/Vite 构建。
- 使用 Tauri 开发模式启动，不生成 release 安装包。
