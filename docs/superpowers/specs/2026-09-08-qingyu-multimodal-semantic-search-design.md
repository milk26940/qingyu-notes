# 轻羽多模态语义检索设计

## 目标

在保留 SQLite FTS5 精确搜索的基础上，接入用户可配置的 `qwen3-vl-embedding`，提供文本与图片的语义索引、混合检索和 Agent 按需检索。页面编辑、打开和保存不得依赖网络成功。

## 核心决策

- 页面与区块继续以 `qingyu.sqlite3` 为权威数据源。
- 图片文件继续保存在附件目录；数据库只保存引用和派生向量。
- Embedding 向量属于可重建索引，模型、维度或切分版本变化时重建。
- 默认模型 `qwen3-vl-embedding`，默认维度 `1024`。
- URL、模型、维度和启用状态由设置界面配置；API Key 单独加密保存，不进入 SQLite、日志、备份或导出包。
- 精确搜索与语义搜索并行，失败时自动保留 FTS5 结果。

## 数据与接口

- `embedding_config`：模型、URL、维度、启用状态和索引版本。
- `block_embeddings`：区块 ID、页面 ID、内容哈希、模态、向量和模型信息。
- `embedding_jobs`：待处理、处理中、完成和失败状态。
- Tauri 命令：读取/保存配置、测试连接、重建索引、读取状态、混合搜索。

## 索引流程

首次启用或点击重建时扫描现有区块。页面保存后只比较内容哈希并更新变化区块。请求在后台执行；失败任务保留并可重试。纯文本使用文本输入，图片使用附件内容与页面标题/相邻文字生成多模态输入。

## 搜索与 Agent

搜索页提供“placid精确/混合/语义”模式，混合模式合并 FTS5 与向量相似度并去重。Agent 只在跨库查找资料时调用语义检索，不自动提交当前页面全文。

## 安全与失败处理

- Windows 使用 DPAPI 加密 API Key。
- 所有错误信息脱敏。
- 401 不重试，429 和网络错误延迟重试。
- API、索引或配置不可用时不影响页面编辑、保存和 FTS5。
- API Key 不随轻羽无损包、Markdown ZIP 或备份导出。

## 验收

- 设置界面可填写 URL、Key、模型和维度并测试连接。
- API Key 不以明文落盘。
- 中文语义查询能返回相关区块并定位页面。
- 页面保存不等待远程 Embedding。
- 索引可重建，进度和错误可见。
- 断网时精确搜索和笔记编辑正常。
