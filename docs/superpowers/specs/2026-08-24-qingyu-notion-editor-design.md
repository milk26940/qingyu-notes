# 轻羽 Notion 式编辑与 Agent 历史设计规格

日期：2026-08-24

## 1. 目标与边界

本轮在保持“Markdown/JSON 文件为权威数据”的前提下，为轻羽补充接近 Notion 的页面编辑体验：无限嵌套子页面、页面与区块引用、图片附件、普通文档页与数据库条目页的一致正文能力、页面内 AI 生成/总结/改写、Agent 历史查看和切换、Inter 默认字体及全局文字字号调节。

本轮不实现多人协作、云同步、数据库看板/日历、任意网页图片托管、对话删除与重命名，也不将正文迁移到 SQLite 或自研独立块编辑器。

## 2. 编辑器架构

CodeMirror 6 继续作为唯一正文编辑内核。Markdown 文件仍可被其他编辑器直接读取；轻羽通过 Decorations、ViewPlugin、Widget 和补全扩展，将标题、页面引用、图片和块级元素显示为接近 Notion 的所见即所得界面。

普通文档页与数据库条目页共用同一 Markdown 编辑器。数据库条目页在正文上方显示数据库属性，正文仍保存于该记录页面对应的 Markdown 文件。

编辑器扩展按职责拆分：

- `notionTheme`：Inter 字体、段落、标题、列表、引用和代码视觉样式。
- `pageMention`：监听 `@`，搜索并插入稳定页面引用。
- `blockIdentity`：维护块 UUID，隐藏内部标记并提供定位能力。
- `imageAttachment`：处理粘贴、拖放、选择文件和图片 Widget。
- `inlineAgent`：读取当前选区、展示 AI 命令和 diff 接受/拒绝状态。

## 3. 页面树与页面形态

页面层级继续由 Page 的 `parentId` 表达，不设置深度上限。侧边栏递归展示任意层级，并在移动页面时拒绝把页面移动到自身或其后代下，防止形成环。

普通页面和数据库条目页的正文顶部都提供“创建子页面”入口。创建成功后，新页面同时出现在当前页面的子页面区域和侧边栏目录树中。

页面保留两种用户可见形态：

- 普通文档页：用于笔记、方案和 Wiki，支持完整 Markdown、页面引用、区块链接、图片和行内 AI。
- 数据库条目页：数据库每行对应一个独立 Page，打开后显示属性和完整 Markdown 正文，支持与普通文档页相同的引用、图片和 AI 能力。

## 4. 页面引用与区块链接

页面引用使用 Page UUID 作为稳定身份，显示页面标题。持久化形式为内部 Markdown 链接：

```markdown
[页面标题](qingyu://page/<page-uuid>)
```

输入 `@` 时弹出可键盘导航的页面搜索菜单；选择页面后插入引用。点击引用时由轻羽拦截协议并打开目标页面。页面重命名或移动不改变 UUID；编辑器显示引用时按 UUID 从当前索引解析最新标题，因此不需要批量改写其他 Markdown 文件。

每个可定位 Markdown 块拥有稳定 UUID，持久化为紧邻块内容的内部 HTML 注释：

```markdown
<!-- qy:block:<block-uuid> -->
```

该标记在所见即所得界面中隐藏。复制页面链接生成 `qingyu://page/<page-uuid>`；复制区块链接生成 `qingyu://page/<page-uuid>#<block-uuid>`。打开区块链接时先加载页面，再滚动到目标块并短暂高亮。若块已删除或旧文件没有对应标记，则退化为只打开页面并提示“原区块不存在”。

## 5. 图片附件

用户可以通过剪贴板粘贴、拖放或文件选择插入图片。轻羽将图片复制到：

```text
.noteapp/assets/<page-uuid>/<asset-uuid>.<extension>
```

Markdown 仅保存笔记库相对路径和替代文本。文件名不信任原始输入，扩展名与实际支持格式经过校验；相同页面内的重名由 UUID 消除。页面移动和重命名不影响附件路径。

备份快照与 ZIP 导入导出包含附件，但继续排除 Codex 登录文件、Codex SQLite、CCSwitch SQLite 和轻羽备份对象目录。图片缺失或格式无效时显示占位符，不阻止正文打开。

## 6. 页面内 AI

选中文字后显示“生成”“总结”“改写”命令：

- 生成：在光标或选区后产生新内容。
- 总结：以选区为输入，生成精简结果。
- 改写：以选区为输入，生成替换文本。

请求通过现有本机 Codex App Server 执行，范围固定为当前页面。输出先作为候选结果和 diff 展示；只有用户点击接受才写入 CodeMirror 文档，拒绝或请求失败均不改变正文。接受后的修改进入现有页面历史和自动保存流程。

行内 AI 操作写入当前页面范围的轻羽 Agent 对话；若没有合适的当前对话，则自动创建一条以操作类型和页面标题命名的对话。轻羽只保存可见输入、输出、工具摘要、diff 和审批状态，不保存隐藏推理或 Codex 内部数据。

## 7. Agent 历史查看与切换

Agent 标题栏保留“新建对话”，新增独立的“历史对话”按钮。点击后打开窄面板内的弹出列表，列表项显示：

- 对话标题。
- 上下文范围：当前页面、当前数据库或整个笔记库。
- 最后更新时间。
- 当前对话选中状态。

列表按更新时间倒序，可滚动。点击列表项调用现有 `conversation_history`，恢复完整消息、计划、diff 和工具状态。原横向对话标签移除，避免对话增多后挤压面板。当前范围不影响已存在对话的原始 scope。

本轮不增加删除、重命名和全文搜索，避免扩张历史管理范围。

## 8. Scope 数据兼容

新的前后端接口统一使用 `pageId` 和 `databaseId`。Rust 对旧 JSON 中的 `page_id`、`database_id` 保留反序列化别名，读取后继续正常显示；再次写入时使用 camelCase。

创建当前页面或当前数据库对话时，前端必须提交对应 UUID。若页面未选中，则自动回退到全库范围，不发送缺少 ID 的 scope。

## 9. 字体与字号

轻羽内置 Inter 可变字体资源，不依赖系统是否安装。界面和 Markdown 正文默认使用 Inter；代码块与行内代码继续使用等宽字体。

字号调节只改变文字，不整体缩放图标、面板和间距：

- `Ctrl +`：增加 10%。
- `Ctrl -`：减少 10%。
- `Ctrl 0`：恢复 100%。
- 范围：80% 至 150%。

当前比例写入轻羽自己的 `localStorage`，启动时恢复。输入法组合期间不处理快捷键；达到上下限时保持不变。所有固定字号通过统一 CSS 变量计算，CodeMirror 同步读取该比例。

## 10. 错误与安全处理

- 页面移动形成环时拒绝操作并显示明确错误。
- 失效页面引用保持可见但标记“页面不存在”。
- 失效区块链接退化为打开页面。
- 图片复制失败时不向正文插入失效路径。
- AI 请求失败、被中断或被拒绝时不修改正文。
- Agent 历史读取失败只影响对应对话，不清空其他历史。
- 所有页面、区块和附件路径均以 UUID 与笔记库根目录约束，拒绝路径穿越。

## 11. 验证策略

测试规模聚焦关键行为：

- Rust：页面树循环拒绝、scope 新旧字段兼容、附件路径约束、页面与区块链接解析。
- 前端：`@` 选择和跳转、区块定位、图片插入、行内 AI 接受/拒绝、Agent 历史切换、字号快捷键与持久化。
- 集成：数据库条目页打开并编辑正文；页面重命名/移动后 UUID 引用继续跳转；旧对话 scope 可读取并继续发送。
- 发布：构建 NSIS 安装包，在临时笔记库验证粘贴图片、复制链接、重启后字号恢复、Agent 历史切换和 Codex 连接。

不使用用户正式笔记库执行破坏性恢复或批量修改测试。

## 12. 验收标准

- 任意深度页面都能在正文和侧边栏创建、显示与导航。
- 普通页和数据库条目页都支持 Markdown、图片、引用与行内 AI。
- 页面重命名或移动后页面引用仍可用。
- 区块链接可以精准定位，缺失时安全退化。
- Agent 历史可以查看、切换并在重启后恢复。
- 当前页面和数据库 scope 不再出现缺少 `page_id` 或 `database_id`。
- 默认字体为内置 Inter，字号快捷键与持久化符合约定。
- 新增能力不读取、复制、显示或备份 Codex/CCSwitch 凭据与数据库。
